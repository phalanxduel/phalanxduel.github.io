# Issue tracker

This project uses the [Backlog.md MCP](https://github.com/phalanxduel/phalanxduel.github.io/blob/main/backlog/config.yml) for all task management, issue tracking, and project planning. 

- Agents should use the Backlog MCP tools (`mcp_backlog_task_create`, `mcp_backlog_task_list`, etc.) to interact with tasks.
- The source of truth for all work is the `backlog/` directory.
