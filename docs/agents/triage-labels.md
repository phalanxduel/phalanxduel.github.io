# Triage labels

The following triage labels are used within the Backlog.md workflow to manage task lifecycle:

- `needs-triage`: Tasks requiring evaluation (default status: Draft/To Do).
- `needs-info`: Tasks waiting for input from the reporter.
- `ready-for-agent`: Tasks fully specified and ready for AFK-ready agent execution.
- `ready-for-human`: Tasks identified as requiring human intervention.
- `wontfix`: Tasks marked as closed without action.
